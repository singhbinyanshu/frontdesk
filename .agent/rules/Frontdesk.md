# Rules for the AI agent

- Always read docs/RULES.md before planning or coding.
- Never invent business rules. If something is missing or unclear, stop and
  add a question to docs/DECISIONS.md instead of guessing.
- Every rule must have an automated test named after its rule ID (for example
  "T5: Friday 18:00 ticket is not late on Sunday").
- Explain every new file in simple language.
- Keep the code small and readable. No extra libraries without asking.
- Never put secrets in code. Use environment variables.
- Work on one task at a time and wait for my review.
